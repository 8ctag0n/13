# Verticals

ZyberLink powers multiple specialized verticals, each leveraging privacy-preserving computation for specific use cases.

## Available Verticals

### [DeFi](defi.md)
Decentralized finance primitives including private markets, lending, and confidential betting.

### [Governance](governance.md)
Futarchy-based governance systems with anonymous voting and privacy-preserving proposal evaluation.

### [Identity](identity.md)
Proof-of-Innocence (POI) and compliance tools that verify user properties without revealing sensitive data.

### [pBTCFi](pbtcfi.md)
Private Bitcoin Finance on Starknet, enabling confidential lending and collateral management for Bitcoin assets.

### [Private Lending](private_lending.md)
Encrypted Loan-to-Value (LTV) calculations and collateral management ensuring borrower privacy.
