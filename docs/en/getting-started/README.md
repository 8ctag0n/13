# Getting Started

Welcome to ZyberLink! This section will help you get up and running quickly.

## Quick Links

* [Quickstart](quickstart.md) - Get ZyberLink running in minutes
* [Demo](demo.md) - Run the interactive demo

## What You'll Learn

In this section, you'll learn how to:

- Set up your development environment
- Deploy the ZyberLink marketplace
- Run a prover node
- Execute your first FHE computation
- Monitor jobs and provers

## Prerequisites

Before you begin, make sure you have:

- Rust 1.75 or later
- Solana CLI 2.1 or later
- A Unix-like environment (Linux, macOS, WSL)

Ready to start? Head to the [Quickstart guide](quickstart.md)!
