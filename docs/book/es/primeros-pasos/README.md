# Primeros Pasos

¡Bienvenido a ZyberLink! Esta sección te ayudará a comenzar rápidamente.

## Enlaces Rápidos

* [Inicio Rápido](inicio-rapido.md) - Pon ZyberLink en marcha en minutos
* [Demo](demo.md) - Ejecuta el demo interactivo

## Qué Aprenderás

En esta sección, aprenderás a:

- Configurar tu entorno de desarrollo
- Desplegar el marketplace ZyberLink
- Ejecutar un nodo prover
- Ejecutar tu primera computación FHE
- Monitorear trabajos y provers

## Prerequisitos

Antes de comenzar, asegúrate de tener:

- Rust 1.75 o posterior
- Solana CLI 2.1 o posterior
- Un entorno tipo Unix (Linux, macOS, WSL)

¿Listo para empezar? ¡Ve a la [guía de Inicio Rápido](inicio-rapido.md)!
